# Project Summary

## Team Name

Bug Squashers

## Project Title

Smart Shopping Comparison and Budget Optimizer

## Problem Statement

Online shoppers often visit multiple websites to compare the same product. This takes time and may lead to overspending. The project solves this by showing product prices from multiple platforms and recommending the best option within a user-defined budget.

## Main Modules

1. **Product Search Module**
   Helps users search and retrieve products quickly.
2. **Price Comparison Module**
   Compares prices from multiple platforms and identifies the best deal.
3. **Budget Optimizer Module**
   Suggests products that fit within a user's budget.
4. **Database Module**
   Stores product, platform, and user budget information.

## Features

- Product search and filtering
- Price comparison across platforms
- Sorting by price
- Budget-based recommendations
- Responsive and user-friendly interface
