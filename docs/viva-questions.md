# Viva Preparation

## 1. What is the aim of the project?

The aim is to help users compare product prices across platforms and find the best products within a fixed budget.

## 2. Why did you choose this project?

Many users compare the same product manually on different shopping websites. This project saves time and supports smarter buying decisions.

## 3. What are the major modules?

- Product search
- Price comparison
- Budget optimizer
- Database management

## 4. Why is C++ used in the backend?

C++ is used to implement the main logic and algorithms efficiently, especially sorting and searching operations.

## 5. Which algorithms are used?

- **Binary Search** for fast searching in sorted data
- **Merge Sort** for efficient price sorting

## 6. Why is SQLite used?

SQLite is lightweight, simple to use, and suitable for student projects that need local structured data storage.

## 7. How does the budget optimizer work?

It checks which products are available within the user's budget and recommends the best affordable option.

## 8. What is the future scope?

- Real-time API integration with e-commerce platforms
- User login and profile management
- Price history tracking
- Wishlist and alert system
